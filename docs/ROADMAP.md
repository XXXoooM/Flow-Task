# FlowTask 路线图

采用语义化版本；主题式演进。已完成项随 `v1.0.0` 一并交付。

## ✅ 已完成（v1.0.0）

### 核心（P0–P5）
- 无边框窗口 + 自定义标题栏 + 设计系统（Tailwind v4 令牌 / 主题切换）
- 任务 CRUD + SQLite 持久化 + 全局搜索/筛选 + 撤销
- 拖拽排序、子任务、多色标签、优先级/日期选择器
- 日历视图（FullCalendar 月/周，拖拽改期）、看板视图（自定义列 + 跨列拖拽）、重复任务
- 番茄钟 + 专注统计、系统通知、托盘倒计时、全局快捷键、开机自启、Markdown 详情
- 命令面板（Ctrl+K）、设置页、数据导出（JSON/CSV）与导入、虚拟列表、打包

### UX 深化（v1.1 / v1.2 / v1.5）
- v1.1：内联编辑、自然语言快添、撤销/重做全覆盖、智能默认值、上下文快捷操作
- v1.2：全键盘操作、通知分级、状态可见性、空状态引导、拖拽容错
- v1.5：渐进式披露、色盲友好模式

### 双模式（v1.3）
- 日程模式（`scheduled_at`）、模式切换、时间/提醒选择器
- 提醒引擎（到期/提前量/冷却/免打扰/专注排队/错过补发）
- 24h 时间轴视图（现在线 + 拖拽调时间 + 日期导航）
- 提醒中心（未读红点 + 集中回看）
- 日程自然语言语法（`明天下午3点 !remind15`）
